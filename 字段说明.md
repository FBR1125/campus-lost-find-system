user表

| 字段名          | 类型           | 约束     | 字段说明                     |
|--------------|--------------|--------|--------------------------|
| id           | int          | 主键、自增  | 用户ID（账号）                 |
| username     | varchar(50)  | 非空、唯一  | 用户名                      |
| password     | varchar(100) | 非空     | 用户登录密码                   |
| phone        | varchar(11)  | 可空     | 用户手机号码                   |
| create_time  | datetime     | 默认当前时间 | 用户账号创建时间                 |
| role         | varchar(20)  | 默认user | 用户角色：user为普通用户，admin为管理员 |
| avatar       | longtext     | 可空     | 用户头像                     |

item表


| 字段名          | 类型           | 约束       | 字段说明                      |
|--------------|--------------|----------|---------------------------|
| id           | int          | 主键自增     | 物品id                      |
| user_id      | int          | 外键关联user | 发布该物品的用户                  |
| name         | varchar(100) | 非空       | 物品名称                      |
| description  | text         | 可空       | 物品详细描述                    |
| status       | tinyint      | 默认0      | 物品状态，1为已认领，0为未认领          |
| create_time  | datetime     | 默认当前时间   | 物品发布时间                    |
| type         | int          | 可空       | 物品类型，0丢失，1找到              |
| place        | varchar(200) | 可空       | 丢失/发现物品地点                 |
| contact      | varchar(50)  | 可空       | 物品发布者联系方式                 |
| check_status | tinyint      | 默认0      | 审核状态，0=待审核，1=审核通过，2=审核不通过 |
| found_status | int          | 默认0      | 找回状态，0=未找回，1=已找回          |


claim表

| 字段名         | 类型           | 约束        | 字段说明             |
|-------------|--------------|-----------|------------------|
| id          | int          | 主键、自增     | 认领记录id           |
| item_id     | int          | 外键关联item表 | 被认领物品id          |
| user_id     | int          | 外键关联user表 | 发起认领的用户id        |
| message     | varchar(255) | 可空        | 认领说明/留言          |
| status      | int          | 默认1       | 认领状态，0=待认领 1=已认领 |
| create_time | datetime     | 默认当前时间    | 认领提交时间           |
