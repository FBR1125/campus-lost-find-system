# 五、系统测试

# 1\. 测试方案

# 

# （1）测试方法

# 

# 本次系统测试采用黑盒功能测试方法，基于电脑端主流浏览器开展全流程手动可视化测试。通过人工进行页面访问、按钮点击、信息输入、表单提交、数据查询、页面跳转等实操操作，逐项校验系统各业务功能的完整性与可用性，验证页面交互逻辑、数据展示效果、权限控制规则是否符合设计需求，完成系统阶段性功能测试工作。

# 

# （2）测试范围

# 

# 功能范围：覆盖系统全部核心业务模块，主要包括用户模块（注册、登录、个人中心管理）、失物管理模块、招领管理模块、认领管理模块、管理员后台管理模块，完整覆盖普通用户前台操作、管理员后台审核管理的全部业务流程。

# 

# 非功能范围：针对电脑端主流浏览器开展兼容性测试，验证页面布局、按钮交互、表单提交的适配效果；同时开展系统易用性与基础安全性测试，校验表单校验机制、用户权限分级、非法操作拦截等基础安全功能。

# 

# （3）测试环境

# 

# 硬件环境：Windows 10 电脑（CPU i5、8G 内存），全程基于电脑端设备完成所有测试工作。

# 

# 软件环境：Chrome 浏览器、Edge 浏览器、MySQL 8.0 数据库、Java 运行环境。

# 

# 2\. 测试结果

# 

# 本次中期测试通过电脑端手动逐项操作验证系统所有核心功能，整体测试结果如下：

# 

# 系统整体运行稳定，所有核心业务功能均可正常使用。用户登录、账号注册、首页浏览、失物与招领信息发布、物品认领申请、个人中心管理、管理员后台审核、用户管理、权限隔离等功能均运行正常，页面跳转流畅、数据展示准确、表单提交合规有效，按钮交互、页面布局适配电脑端主流浏览器，基础安全校验机制生效，整体满足项目中期功能使用需求。

# 

# 同时在测试过程中完成用户信息界面优化，优化后个人中心信息展示规整清晰，界面美观度与用户使用体验得到有效提升。

# 

# 3\. 问题与改进

# 

# （1）测试发现的主要问题

# 

# 账号注册环节存在用户ID无长度限制问题，输入过长账号ID时，会出现数据适配异常，不符合系统账号注册规范。

# 

# （2）对应改进措施

# 

# 针对上述问题，对系统注册功能进行专项优化，新增用户ID长度限制校验机制。前端增加输入长度实时校验，后端同步匹配长度校验规则，当用户输入过长账号ID时，系统自动拦截提交操作并给出合法提示，规范用户注册输入格式，解决账号ID长度异常问题，目前该问题已完全修复，注册功能运行正常。

# 

# 4\. 测试总结

# 

# 系统测试完成了全模块功能验证，系统整体功能完整、运行稳定，仅发现一项账号注册长度适配问题并已完成优化修复。同时完成个人信息界面展示优化，系统可用性、规范性得到提升。现阶段系统核心业务流程通畅，无功能性BUG，满足项目验收标准，可正常开展日常使用，后续将持续细化测试，完善系统细节体验。
